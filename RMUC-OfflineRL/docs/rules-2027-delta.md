# RMUC 2027 规则差异与既有章程的影响评估

> 依据：《RoboMaster 2027 机甲大师超级对抗赛比赛规则手册 V1.0.0（20261015）》
> 基线：《RoboMaster 2026 机甲大师超级对抗赛比赛规则手册 V1.0.0（20251021）》
> 本文**不修改**任何既有文档，只诊断影响。代码未改动。

## 1. 结论摘要

本章程自 V1.0.0 起**只对齐 2027**。数据集（2026 区域赛，613 局）的用途**收窄为"人类走位先验"**，不再作为任何 2027 规则量的证据来源。

这一决定有三处直接后果：

1. `docs/plans/radar-waypoint-layer.md` 的**三层目标函数第一层作废**——"前哨站掉血/击毁"在 2027 下不是胜负函数的主体。
2. 阶段 1 原计划的"以被标记进度做确定性基线"**降级为方法学验证**，不是结论。
3. ADR-0004 关于评估的结论**仍然成立且更重要**，但"可算的目标函数"从易伤秒数换成**控制度累积**。

## 2. 逐项差异

### 2.1 胜负判定（§5.8）——本项目最重要的改动

| | 2026 | 2027 |
|---|---|---|
| 第 1 条 | 时间耗尽**或**基地被击毁 → 基地剩余血量高者胜 | **仅**一方基地被击毁时判 |
| 第 2 条 | 血量相同 → 前哨站剩余血量 | **双方基地均未毁且时间耗尽 → 累计控制度高者胜** |
| 第 3 条 | 仅一方前哨站被击毁过 → 未毁方胜 | 控制度一致 → 全队攻击伤害 |
| 第 4 条 | 前哨站血量相同 → 全队攻击伤害 | 伤害一致 → 全队总剩余血量 |

**关键**：2026 的整个"基地血量 → 前哨站血量 → 攻击伤害"比较链被**删除**,替换为单一的"累计控制度"。**控制度不是新增的一层,它替换了整个血量比较体系。**

### 2.2 控制机制（§5.6.2）——目标函数的新主体

- 双方各有 **2 个阵地**:前哨阵地、基地阵地
- 控制状态分**临时控制**与**完全控制**;开局双方**完全控制己方**的两个阵地
- **累计控制度速率**:控制全部 2 个前哨阵地 = 每秒 **+1**;控制全部 2 个基地阵地 = 每秒 **+3**
- 七分钟理论上限 ≈ 420 × 4 = **1680**（与规则违规判罚中出现的"控制度 1680"一致）

控制状态转化（表 5-21）：

| 转化 | 方式 |
|---|---|
| 对方完全控制 → 己方临时控制 | 己方**连续激活**构成该阵地的任一增益点 **5 秒** |
| 对方临时控制 → 己方完全控制 | 对方机器人**不激活**该阵地任一增益点**连续 5 秒**;若连续激活未满 5 秒后停止,占领进度**均匀倒退**（速度与增速一致） |
| 对方完全控制的前哨阵地 → 对方临时控制 | **击毁**该阵地上的前哨站 |
| 己方临时控制的前哨阵地 → 己方完全控制 | **击毁**该阵地上的前哨站 |

阵地构成：

- **前哨阵地** = 前哨站增益点 + 中央高地增益点
- **基地阵地** = 基地增益点 + 堡垒增益点（完全控制**仅限初始拥有方**）

**对位置问题的含义**：占点不是"路过触发",而是**必须停留满 5 秒的持续性动作**。位置价值可直接写成"在该点停留的连续时长 → 占领进度"的确定性函数。

### 2.3 激活的物理判据（§5.3.1 等）

> 当机器人的场地交互模块检测到补给区场地交互模块卡，或机器人位于规则设定下的补给区时，机器人的相机图传模块识别到补给区视觉标签，均视为其位于补给区。存活机器人位于己方补给区时，视为激活补给区增益点。

**位于某区域 ≡ 激活该区域的增益点。** 这是本项目"位置即决策"的规则基础——位置不是间接影响胜负,它**直接就是**胜负变量的自变量。

### 2.4 阵容（§3.1 表 3-1 / 3-2）

| 变化 | 内容 |
|---|---|
| 合并 | **英雄机器人 + 工程机器人 → 重装机器人**（编号 1） |
| 地面机器人 | 仅 3 类:重装 / 步兵 / 哨兵 |
| 最低阵容 | 至少 **3 台地面机器人**（2026 为"除雷达与飞镖外至少 4 台"） |
| 操作手 | **哨兵操作手 0 人**（与 2026 一致）;取消云台手与飞手,新增**指挥手**与**安全员** |

数据影响：现有 `rm_rl/data/schema.py` 的 8 类实体与 2027 地面 3 类**不对应**。`MOBILE_TYPES` 中的 `英雄`/`工程` 在 2027 已不存在。

### 2.5 哨兵机制（§5.7.2）——本项目的新发现

**自动 / 半自动**：自检阶段前由指挥手选择,未选默认**自动控制**。指挥手可干预自动哨兵,但**每操作一次花费 50 金币**;半自动哨兵不消耗金币。

指挥手可下发的指令：转发小地图标记、购买允许发弹量、确认复活、远程兑换发弹量、远程兑换血量、远程兑换立即复活、**切换姿态**。

**姿态系统**（表 5-28）：

- 开局默认**移动姿态**;切换冷却 **5 秒**;单个姿态累计超过 **3 分钟**效果下降
- 每种**强化姿态**至多累计 **15 秒**,计时相互独立
- **三种姿态默认与强化效果均附带"获得 25% 易伤"**
- 移动姿态:强化得 **200W 底盘功率上限** + 1.5 倍功率增益,但热量冷却降为 1/3

**这是本章程此前完全未考虑的机制**,且与位置高度耦合：移动姿态利于占点转移,但带来 25% 易伤与冷却惩罚。姿态切换有 5 秒冷却,**不能高频**。

### 2.6 雷达机制（§5.7.4）

机制**基本沿用 2026**：`P ∈ [0,150]`、准确 `<0.8m` / 半准确 `<1.6m` / 错误 `≥1.6m`、`x` 的 `+1.0 / +0.5 / −0.8` 逻辑、**每累计 0.5 秒未收到数据视为一次错误**、5 Hz/100% → 3.0 秒达 120 的示例、重新解锁的"双倍易伤"。

**唯一实质变化**：2027 的雷达"可识别**双方地面机器人**的位置"——**只有地面机器人可被标记**。空中系统不再可被标记;建筑本来就不在标记范围内。

### 2.7 场地

新增制高点、机库平台、工作台;取消飞行区、无线充电装置放置区、停机坪。增益点清单新增**制高点增益点**,取消飞坡类地形跨越项。

**这是数据集最根本的失效点**：2026 的走位统计建立在旧地图上。

## 3. 对既有文档的影响矩阵

| 文档 | 状态 | 说明 |
|---|---|---|
| `ADR-0001` 决策承载于雷达 | **仍然成立** | 通信单向性与观测正当性不依赖赛季规则 |
| `ADR-0002` 两条通道分离 | **仍然成立** | 雷达上送与多机通信机制未变 |
| `ADR-0003` 特权信息蒸馏 | **需修订** | 人类走位先验的适用范围收窄;哨兵校验改用 2027 可达性 |
| `ADR-0004` 确定性反事实评估 | **仍然成立且更重要** | 目标函数从"易伤秒数"换成"控制度累积" |
| `plan §6` 三层目标函数 | **第一层作废** | "前哨站掉血/击毁"不是 2027 胜负主体,须改为控制度 |
| `plan §7` 阶段 1 | **降级** | 进度基线从"确定性裁判"降级为"方法学验证" |
| `GLOSSARY.md` | **需新增/修订** | 新增:控制度、阵地、临时/完全控制、激活、姿态;修订:战术核心、前哨站门控(2027 下不再是基地的钥匙) |

## 4. 新目标函数（按 2027 重写）

```
J = ∫ 控制度速率 dt                                     ← 主项，第一层
  = Σ_t [ 1{控制全部 2 个前哨阵地}(t) × 1
        + 1{控制全部 2 个基地阵地}(t) × 3 ]
  + 辅助项：占领进度的推进量（含"还差 5 秒"的紧迫窗口）
  + 次级项：被标记进度的易伤收益（仅地面机器人）
  − 惩罚：中断激活导致的占领进度倒退
```

三项性质值得写进章程：

1. **基地阵地权重是前哨阵地的 3 倍**——控制基地阵地的重要性远高于直觉。
2. **"连续 5 秒"是硬门槛**——位置的有效性取决于**停留时长**,不是**经过次数**。这直接否定了"巡游式"走位。
3. **激活中断会匀速倒退**——这给"守点"一个可量化的成本:放弃一个已推进 80% 的进度,损失的是那 80%。

## 5. 数据集用途的重新界定

**仍可用**（与规则无关的人类行为先验）:

- 人类如何在场地移动、如何在目标间切换、走位的空间分布与熵
- 导航作为连续回归任务的可学性与误差量级

**不可用**（规则/地图/阵容相关）:

- 任何 2027 控制度的计算——旧地图、旧胜负函数
- 任何基于 2027 阵地的"位置价值"——增益点位置已变
- 任何"战术核心"的兵种维度——英雄/工程已合并为重装
- 任何 2027 姿态相关的推断——2026 无该机制

## 6. 待确认（阻塞项）

1. **2027 增益点的实际坐标**:手册有图 5-23 分布示意图,但**未给出可机读坐标**。没有它就**无法把位置映射到控制度**。需要实测或从示意图标定。
2. **2027 场地尺寸与坐标系原点**是否与 2026 一致（28×15 m、原点在有效区内角）。若不一致,2026 的走位先验也要做坐标变换。
3. 2027 是否有公开比赛数据集。若没有,2027 规则下的任何"从数据学习"都失去观察来源,项目重心应转向**基于规则的占点规划**,而不是学习。
4. 战队在 2027 打算让哨兵跑**自动**还是**半自动**——这决定指挥手 50 金币/次的经济约束是否进入我们的优化问题。
