# ADR-0004 用确定性反事实回放代替 FQE，且不做负塑形

- 状态：已接受
- 日期：2026-02（章程落笔时）

## 背景

仓库的离线评估手段已经失效，且这一点被写进了 README：

- FQE 的 `Δ = J(策略) − J(行为)` 绝对值几乎全是估计器偏置。判据是 BC 作为行为的直接模仿，其 Δ 本应约为 0，实测却是 −8.92 / −10.57。
- 成因是日志行为随机多模态而评估用确定性动作，Q 落在支撑集外，twin-Q 取 min 系统性悲观。
- 以同域 BC 为零点对消后，全部方法落在 ±0.6 内——即相对纯模仿无可测增益。
- 跨兵种评估被判为结构性不可用：Q 函数只会在策略偏离时扣分，不会因偏离得更好而加分，而"偏离"正是引入外部老师的目的。

结论是：**在 420 步时域上用一条策略的日志评估另一条行为差异较大的策略，现有离线手段做不到。**

而本项目有一个仓库此前没有的性质：**被标记进度的演化由规则完全确定**（准确 / 半准确 / 错误的判定、超时判错的规则、阈值与收益），因此可以绕开价值函数。

## 决策

1. **评估用确定性反事实回放**：在真实日志上以规则动力学推演"若改用另一套航点会怎样"，不训练也不查询任何 Q 函数。
2. **奖励采用三层结构**，且**不做负塑形**：

   - 第一层（规则锁定的胜负门控）：敌方前哨站掉血与击毁。在前哨站存活期间**不给基地伤害计分**（基地无敌）。
   - 第二层（战术核心压制）：工程机器人的压制与死亡、其装配成功次数（反向计分）、英雄机器人死亡等。**战术核心是动态量，不是固定兵种。**
   - 第三层（雷达唯一能作用的一层）：被标记进度 ≥ 阈值的高易伤秒数，其权重由第二层决定。
   - 次优先：己方情报、双倍易伤窗口的有效利用。
3. **惩罚只来自硬约束与机会成本**：超时未发送、进度跌破高阈值、把发送配额浪费在低权重目标上。不设负奖励塑形。

## 理由

1. 负塑形依赖 Q 去传播，而 Q 在这个数据上已被证明不可信。任何需要 Q 的奖励项都会把 README 里那个坑重新引入。
2. 易伤本身没有价值——它只是链条中间的一环。把"进度 ≥ 阈值"当主目标是**把手段当成了目的**；真正的价值在于让对胜负门控贡献最大的敌方单位更快死掉。
3. 奖励项的可测性优先于其表达力：宁可少一个精确的项，也不要多一个需要推断的项。

## 后果

- 阶段一可以在**不训练任何网络**的前提下产出一个确定性裁判，并给出人类雷达在真实战况下的实测表现作为对照。
- 训练信号是**带权重的监督学习**，不是时序奖励回传。权重偏向"高进度 / 战况窗口 / 高回报"的样本。
- 奖励权重是**公开的偏好**，写死在 config 中并支持消融，**不声称**从数据中学得——因为标记与伤害互为因果，从胜负反推权重会把相关当因果。
- "到达后保持"这一行为在监督信号上有语义冲突：若标签是"未来位置"，哨兵提前到达并停住会被惩罚。需以显式的"保持"维度或等价机制处理，不能靠降权掩盖。

## 被否决的方案

- **继续用 FQE 判定优劣**：已被仓库实测否定。
- **用 `reward_model.py` 的回归反推奖励权重**：那套在全队级奖励上勉强成立，在雷达这个因果耦合更强的场景下不成立。
- **纯模仿（BC）不加任何权重**：会把行为树的缺陷一并学入，且无从中受益的机制。
